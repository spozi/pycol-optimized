# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 - 2026-07-31

- Added a standalone `pycol-optimized` distribution.
- Added shared float32 PyTorch geometry for CPU, Apple MPS, and CUDA.
- Added deterministic ordered kNN graph construction.
- Added optimized F1, class-balanced N3, kDN, CM, and C1.
- Retained the optimized deterministic N1 implementation.
- Added single-label and one-vs-rest multilabel aggregation.
- Added an optional pinned PyCOL 1.0.4 scientific-reference extra.
- Added package, wheel, isolated-install, parity, and device tests.
